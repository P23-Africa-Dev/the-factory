- Open Projects from the top menu to see all projects. Open one to see its task board.
- Owners, admins and supervisors can create a project (name, type, dates, priority, manager, team, territory) and change it later.
- Agents see the projects and tasks they are part of.

ELY can do this for you: "Create a project called Q1 Retail Audit starting Monday", "Mark the Lekki rollout project as completed", "Which projects are at risk?".
